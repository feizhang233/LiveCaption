# 英語與中文核心回歸

日期：2026-11-06。本輪集中統一 App 來源語言配置並補英語／中文回歸；沒有改模型、低延遲參數、VAD 或 Whisper 解碼策略。

`App/Session/SourceLanguage.swift` 是 App 語言選單與偏好驗證的單一來源：優先 `ja`、`fr`、`en`、`zh`，另有 `auto`；其餘語言仍由固定版本的 `WhisperEngine.supportedLanguages` 提供。無效儲存值回到 `ja`，空白與大小寫可正規化。`auto` 傳入引擎時對應 `nil`。

中文選項顯示為「中文（普通話）」並使用 Whisper 的 `zh`。App 不新增繁簡轉換；模型不保證特定輸出字形，也不能據此宣稱所有中文方言已受驗證。`WhisperEngine.transcribe` 保持 `translate = false`，`detect_language = false`；後者使自動語言選擇仍然執行轉寫，而非只回傳偵測結果。

`core-tests.log` 記錄 **39 項測試全部通過**。本輪新增 6 項：

- 從真實固定引擎語言表確認 `en`／`zh`，同時保留日法及其他語言。
- 英文重疊去重保留新詞與 Unicode 標點。
- 簡體與繁體中文分別完成重疊去重，且不把不同字形當作可刪除的相同詞。
- 在稍後時間再次說出的英文／中文相同句子仍保留。
- TXT／SRT 保留原文 Unicode、時間軸與 UTF-8 round trip，略過未確認字幕。
- 排程將 `en`、`zh`、自動選擇參數原樣送往辨識器，保留文字與來源時間。

最後一項使用可控測試辨識器，只驗證排程與文字傳遞，**不是語音辨識的準確率證據**。英語／普通話真人錄音的實際本機推論、App 語言偏好整合與平台測試由本輪其他驗證分開記錄。此核心回歸未啟動模型推論。
